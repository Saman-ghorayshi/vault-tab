Quick Start

Install VaultTab in 30 Seconds

VaultTab runs natively on all modern Chromium browsers as an unpacked Manifest V3 extension. No tracking, no external accounts, no cloud dependencies.

  1. Clone or Download the Repository

    Clone the source from GitHub or download the latest zipped release:

    git clone https://github.com/Saman-ghorayshi/vault-tab.git

  2. Enable Developer Mode

    In your address bar, navigate to chrome://extensions (or brave://extensions) and toggle the Developer mode switch in the top right corner.

  3. Load Unpacked Extension

    Click the Load unpacked button and select the vault-tab folder. VaultTab will instantly appear in your toolbar.
